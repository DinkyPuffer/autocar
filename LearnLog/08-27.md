二、 详细任务与实现细节

1. OpenHarmony系统驱动实验 - GPIO驱动超声波测距（HC-SR04）
   - 硬件引脚与工作原理：
     * 引脚配置：小车核心板通过 GPIO_7（Trig 触发端）和 GPIO_8（Echo 回响端）连接 HC-SR04 超声波模块。
     * 触发与测距逻辑：GPIO_7 输出至少 10us 的高电平脉冲触发测距；模块自动发送 8 个 40kHz 方波，接收到回响后 GPIO_8 输出高电平。
     * 时间测定：利用 hi_get_us() 获取微秒级时间戳 start_time 与终止时间，计算高电平持续时间 time（单位：us）。
     * 距离换算：依据公式 distance = time * 0.034 / 2，计算出厘米级测距结果。
   - 任务扩展要求实现（创建2个软件定时器）：
     * 定时器1（测距控制）：创建周期为 3 秒的软件定时器，定时触发 GetDistance() 测量距离并输出结果。
     * 定时器2（系统心跳）：创建定时器调用 hi_get_tick() API，实时获取并打印当前系统 Tick 值（SysTick），用于监测多任务调度与运行状态。

2. STM32 TIMER 编码器测速实验
   - 硬件配置与编码器模式：
     * 定时器及引脚：左轮编码器接 PA0、PA1（TIM2），右轮编码器接 PA6、PA7（TIM3）。
     * 采集模式：通过 TIM_EncoderInterfaceConfig() 配置 TIM2 与 TIM3 为 TIM_EncoderMode_TI12 模式（双通道上升沿捕获，实现 4 倍频采集，大幅提升采样精度）。
     * 计数器读取：自动重装载值 ARR 设为 65535，预分频 PSC 设为 0。在 100ms（SysTick 定时）周期中断里调用 Read_Encoder() 读取 TIMx->CNT 的差值并立即清零，获取 100ms 内的脉冲数 L_speed 和 R_speed。
   - 任务扩展要求实现（脉冲换算为真实速度 m/s）：
     * 参数测量与计算：测得小车轮直径 D = 0.065m（周长 C = π * D ≈ 0.2042m），电机线数 360 线，经 4 倍频后电机旋转一圈产生 N = 360 * 4 = 1440 个脉冲。
     * 换算公式：速度 v (m/s) = (100ms内脉冲数 / 1440) * 周长 C / 0.1s。
     * 代码实现：在 System_Control() 中编写换算逻辑，将原始计数转换为实际线速度（m/s）并经串口打印输出。

3. STM32 PID 电机速度闭环控制实验
   - 算法原理与函数编写：
     * 控制原理：采用离散增量式 PID 控制算法。为了消除系统静差并防止电机在不同负载下转速衰减（如电压下降、物理阻力），构建速度闭环。
     * 算法实现：编写 Incremental_PI_A 和 Incremental_PI_B 控制函数，核心公式为 Pwm += Kp * (Error - Error_prev) + Ki * Error + Kd * (Error - 2*Error_prev + Error_prev2)。
     * 保护与限幅：设置 Integral_A / Integral_B 积分限幅（基于 7199 / Velocity_KI），并将最终输出的 PWM 限幅在 [-7199, 7199]（匹配定时器 PWM 重装值）。
   - 驱动与转化（Rs_To_CPR）：
     * 通过 Rs_To_CPR(rads) 函数将目标转速（如 1.0 转/秒）转换为 100ms 内的期望脉冲数 Target = rads * (700 * 4) / 10。
   - 任务扩展要求实现（参数调整与速度响应测试）：
     * 参数调优：调整目标参数 TageA 与 TageB 的输入值（设置正负转速实现直线行驶或转向）。
     * 动态观察：根据小车实际行驶轨迹，独立微调左轮 A 与右轮 B 的 Velocity_KP（如针对阻力偏大的轮子适当增大 Kp），确保小车在不同给定速度下能够快速稳定响应并保持直线行驶。

三、 遇到问题与调试记录
1. 问题：超声波测距时，若模块未收到回响信号，while(1) 轮询 GPIO_8 会导致系统阻塞卡死。
   - 解决：在轮询逻辑中加入超时退出计数（超过一定微秒数未收到高电平/低电平变相即跳出），提高程序鲁棒性。
2. 问题：在速度闭环控制中，给电机施加外力阻挡时，电机输出响应迟钝或出现大幅超调震荡。
   - 解决：对增量式 PI 的 Velocity_KP 进行阶梯式微优，配合抗饱和积分限幅，使电机在受到阻力时能够平稳且快速地增加 PWM 输出以恢复目标转速。
