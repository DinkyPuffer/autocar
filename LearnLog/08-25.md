#今日任务：控制无人车前灯进行跑马灯闪烁
#学习内容：
  1.Linux操作系统常用命令：
        ls:查看目录内容（ls -la 显示隐藏文件与详细信息）
        cd:切换路径（cd .. 返回上级目录，cd ~ 返回主目录）
        pwd:显示当前所在路径
        mkdir:创建文件夹（mkdir -p path/to/dir 递归创建）
        touch:创建空文件（如 touch main.c）
        cp:复制文件或文件夹（cp -r dir1 dir2 复制文件夹）
        mv:移动或重命名文件（mv old.txt new.txt）
        rm:删除文件/目录（rm -rf dir 递归强制删除，慎用）
        cat:查看文件内容
        less:查看文件内容（支持上下翻页查看长文件）
        grep:检索文件内的文本（grep -rn "main" . 在当前目录递归查找）
        find:按文件名搜索路径（find . -name "*.c" 查找所有 .c 文件）
        chmod:修改权限（chmod +x script.sh 赋予可执行权限）
        sudo:以管理员（root）身份执行命令
        df -h:查看磁盘剩余空间
        free -h:查看内存使用情况
        top:查看系统资源占用与进程状态（或 htop）
        tar:解压/打包文件（tar -zxvf file.tar.gz 解压 .tar.gz）
        ping:测试网络连通性
        curl:下载文件或访问网络资源
        wget:下载文件（如 wget url）
  2.Linux操作系统常用快捷键：
        Tab:自动补全（输入命令或路径前几个字母后按 Tab，连按两次提示所有选项）
        Ctrl + C:中断/终止当前正在运行的程序
        Ctrl + L:清屏（等同于输入 clear 命令）
        Ctrl + A:将光标快速移动到行首
        Ctrl + E:将光标快速移动到行尾
        Ctrl + U:删除/剪切光标位置之前的整行内容
        Ctrl + K:删除/剪切光标位置之后的整行内容
        Ctrl + R:搜索历史命令（输入关键字按回车即可快速重复执行旧命令）
        Ctrl + Z:暂停当前任务并放入后台
        ↑ / ↓ 方向键:快速翻阅上一条 / 下一条执行过的历史命令
