一、 实践任务与目标

本次实践任务的目标是基于搭载双芯片（主控：Hi3861，从控：STM32）的小型无人车平台，编写综合控制代码，使无人车能够同时实现以下功能：

利用超声波传感器（HC-SR04）实现前方障碍物实时检测与减速/转向避让。

利用底部的双路红外反射传感器（TCRT5000）实现黑线/黑胶带的识别与避让（防越界/悬崖防跌落）。

协调 Hi3861 传感器数据采集与 STM32 底层电机驱动控制之间的串口通信协议。

二、 主要学习与工作内容

系统架构与底层驱动编写

在 Hi3861 侧完成了 GPIO 引脚初始化与微秒级高精度定时器配置，编写了超声波 HC-SR04 测距驱动（触发脉冲与 Echo 接收时序处理）。

配置 Hi3861 UART2 串口通信接口（波特率 115200），设计并实现了自定义帧结构（0xFC 包头、电机方向、左右电机 PWM 速度、0xFD 包尾），用于向 STM32 发送电机控制指令。

编写多任务控制逻辑，根据超声波距离与左右红外传感器状态，设置优先级动作矩阵：
[优先级1] 超声波测距 < 20cm  => 急刹 + 倒车 + 右转避障
[优先级2] 左侧红外检测到黑线  => 急刹 + 倒车 + 右转避让
[优先级3] 右侧红外检测到黑线  => 急刹 + 倒车 + 左转避让
[优先级4] 状态安全           => 保持正常前进

关键技术难题排查与解决：红外黑线识别失效分析

[问题现象]：无人车在悬崖防跌落测试中表现完美，但在面对赛道标准的黑色电工胶带时，红外传感器彻底失效，无法识别黑线并引发越界。

[原理分析]：
a. 物理机制差异：悬崖场景属于“有地面反射”与“完全无反射（距离无穷远）”的对比，信号对比度极大；而黑线场景属于“浅色地面漫反射”与“黑色表面吸收/反射”的微弱光强差异。
b. 材料特性：表面光滑的 PVC 电工胶带容易产生强烈的红外“镜面反射”，且部分有机染料对近红外光（850nm/940nm）呈透明状，导致接收管接收到的光强与白地面无异。

[代码与硬件定位]：分析当前 Hi3861 C 代码发现，传感器采用了 GPIO 数字量输入（读取高低电平 0/1），硬件电平转换由板载 LM393 比较器完成。因此，单纯在软件代码中无法直接修改数字阈值。

[问题解决]：分析 PCB 硬件原理图（双路红外巡线电路图）与主板布局，定位到 PCB 正面 OLED 屏幕两侧的 SR1/SR2 (10k) 贴片蓝底可调电位器。通过手动旋转微调比较器的参考电压阈值，打破了光滑黑胶带镜面反射带来的误判，成功实现了黑线的精准识别与避让。

三、 实践心得与总结

嵌入式系统是“硬件”与“软件”高度紧密结合的整体。在面对传感器异常时，不能仅局限于修改 C 代码，必须深入分析硬件电路原理图（如 LM393 比较电路、分压电阻等）与物理反射特性。

深刻理解了双芯片分工架构：Hi3861 适合做上层感知与控制决策，STM32 负责底层的实时 PWM 执行，两者通过标准串口协议通信，大大提高了系统的稳定性和扩展性。

掌握了从原理图排查、代码调试到硬件电位器调校的综合工程排错能力。
